# AI-Powered Real Estate Recommendation Chatbot

## Project Overview

An intelligent real estate recommendation system that leverages Natural Language Processing (NLP) and machine learning to interpret user queries and recommend relevant property listings.

## Business Objective

The project aims to improve property discovery within the Lebanese real estate market by providing personalized recommendations based on users' preferences expressed in natural language.

## Key Features

- Natural language query processing
- Text preprocessing and feature extraction
- Semantic similarity analysis
- Property clustering
- Retrieval-based recommendations
- Personalized property matching

## Technologies and Methodologies

- Python
- Natural Language Processing (NLP)
- TF-IDF
- Sentence-BERT embeddings
- Machine Learning
- Clustering
- Information Retrieval
- Scikit-learn

## Project Workflow

1. Property data preprocessing
2. Text cleaning and transformation
3. Feature extraction and sentence embeddings
4. Property clustering
5. User query processing
6. Similarity-based property recommendations

## Skills Demonstrated

NLP, machine learning, recommendation systems, semantic search, AI integration, and business-oriented problem-solving.
